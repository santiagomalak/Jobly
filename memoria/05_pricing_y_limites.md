# PRICING Y LÍMITES

## Piso duro
**USD 120.** Por debajo de eso el radar descarta automáticamente, sin excepción, aunque el
trabajo parezca de 20 minutos. Excepción única: cliente recurrente que ya pagó ≥ $300.

## Tarifa de referencia
- **Por hora (cuando el alcance es difuso o el código es ajeno): USD 25–35/h.**
- **Por proyecto (preferido): usar las tablas de cada módulo.**
- Regla de estimación: calculá las horas honestamente y **multiplicá por 1.4**. Siempre aparece algo.

## Reglas de negociación
1. **Nunca doy el precio primero si no sé el alcance.** Primero 2 preguntas, después número.
2. Si piden descuento: **no bajo el precio, bajo el alcance.** "Por $200 entro con A y B; C queda para una fase 2."
3. **Precio ancla:** doy un rango donde el mínimo es lo que quiero cobrar. "Entre 300 y 380 según X."
4. Si el cliente publicó presupuesto y estoy hasta 20% arriba, cotizo mi número y justifico en una línea.
5. Cambio de alcance a mitad de proyecto = cotización nueva, siempre, sin excepción y sin drama.

## Cobro
- Plataformas: Upwork/Freelancer con escrow para clientes nuevos de marketplace.
- Directo: transferencia internacional / Wise / Payoneer / cripto estable según lo que el cliente use.
- **Adelanto obligatorio** en todo ticket > $250 fuera de escrow.
- Factura simple con detalle de entregables en cada cobro.
